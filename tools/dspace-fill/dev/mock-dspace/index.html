Repositorio UNT — MOCK del ensayo general

Imitación local de DSpace para ejercitar el userscript de VistoBueno sin Tampermonkey y sin tocar la instancia real. Todo corre sobre la API real de VistoBueno (:8000) a través del proxy del mock.

Flujo de la mano (sin terminal):
  1. Abre el formulario de envío
  2. Pulsa "Publicar ficha de prueba" (el botón azul)
  3. El formulario se auto-rellena con el toast de resumen
  4. Revisa: título, autor, DNI, año, Acceso abierto
  5. Marca Confirmo la licencia y pulsa Depositar
  6. En el ítem, el handle se reporta al buzón automáticamente
  7. El papeleo se genera con nix run .#test-ficha-deposito, o con la API real (POST /constancia y POST /fila-registro)

La versión automatizada (todo el flujo de punta a punta con verificaciones) sigue siendo nix run .#test-ficha-deposito. Checklist completo: tools/dspace-fill/dev/mock-dspace/README.md.
